# Игра "Камень--ножницы--бумага"

## Описание
Консольная игра "Камень--ножницы--бумага".



## Как играть
1. клонировать репозиторий https://github.com/Ktulha/rock_paper_scissors.git
2. запустить игру: ```python main.py```


## Функциональность
    - Циклический перезапуск игры
    - Сохранение результатов игры


## Требования
    - python 3.x
